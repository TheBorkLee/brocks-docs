# Getting Support

A complete first message makes it easier to reproduce and resolve your issue.

## Include these details

- Resource name and installed version
- Framework and framework version
- Server artifact version
- Relevant dependencies and their versions
- The complete relevant server console error
- The complete relevant F8 error
- Clear steps to reproduce the problem
- What you expected and what happened instead
- Screenshots or a short video when useful
- Troubleshooting steps you have already tried

<Warning>
Never post license keys, Tebex transaction information, server credentials, database passwords, or other private information in public support channels.
</Warning>
