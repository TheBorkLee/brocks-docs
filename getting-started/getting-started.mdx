# Getting Started

Use this checklist as your starting point for any Brocks Scripts resource.

<Steps>
  <Step title="Download the current release">
    Download the resource from the official purchase channel and keep the archive intact until you are ready to install it.
  </Step>
  <Step title="Read the resource guide">
    Open the resource's overview, requirements, and installation pages. Requirements can vary between resources and versions.
  </Step>
  <Step title="Create a backup">
    Back up any configuration and database data that could be affected before updating a live server.
  </Step>
  <Step title="Install and configure">
    Place the resource in the server resources directory, install confirmed dependencies, and edit only the supplied configuration files.
  </Step>
  <Step title="Start and verify">
    Start the resource in the correct order, review the server and F8 consoles, and test on a development server before production.
  </Step>
</Steps>

<Warning>
Never expose license keys, transaction details, credentials, or database passwords while asking for help.
</Warning>
